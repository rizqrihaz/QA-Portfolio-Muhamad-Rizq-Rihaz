# BelajarBareng QA Testing Portfolio

## Project Overview
Manual testing pada aplikasi Belajar Bareng untuk memvalidasi fitur Login dan Add User.

## Application Information
- Website: https://belajar-bareng.onrender.com
- Environment: Production
- Browser: Chrome, Edge, Firefox

## Scope Testing

### Login
- Valid Login
- Invalid Login
- Empty Username
- Empty Password

### Add User
- Add User dengan data valid
- Add User dengan username duplikat
- Add User dengan field kosong

## Deliverables
- Test Plan
- Test Scenario
- Test Case
- Bug Report
